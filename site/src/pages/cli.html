The eider command line

Sources, search, install, update, launch checks and interface size are all available from the terminal. eider --help lists the commands and eider help <command> explains each.

Basics

The command ships inside the app bundle at Eider.app/Contents/Resources/cli/bin/eider; the Homebrew cask links it onto your PATH. There is also a command-line tarball on each release. eider --version prints the version.

  • JSON output. Every command takes --json: one JSON object per line, and the last line is the result.
  • Exit codes. 0 success, 1 usage error, 2 failure. source import also exits 2 when any address was rejected or failed, after adding the rest.
  • Errors carry a stable code and a sentence you can act on.
  • State lives in Eider's own folder under ~/Library/Application Support/Eider. Set EIDER_HOME to use another folder, for tests and scripts.

A quick tour

eider source add https://example.com/source.json   # add a source
eider source list                                  # sources you added
eider source refresh                               # fetch them all again
eider source export -o sources.json                # save your list of sources
eider source import sources.json                   # add the sources in a file (- reads stdin)
eider search camera                                # find an app
eider info com.example.app                         # what the sources offer
eider install com.example.app                      # newest version, from a source
eider install com.example.app --version 1.2.0
eider install ~/Downloads/App.ipa                  # a file, or an https address
eider list                                         # installed apps, updates marked
eider update --all                                 # or: eider update <bundle-id>
eider open com.example.app                         # launch and confirm it stays up
eider doctor com.example.app                       # launch; if it dies, say why
eider doctor com.example.app --settle 15           # an app that fails late
eider scale com.example.app 115                    # interface size; no reinstall
eider scale --all auto                             # every installed app on Auto
eider uninstall com.example.app --remove-data      # to the Trash

eider source

Add, list, remove, refresh, import and export sources. See Sources for the formats and rules.

eider source add <url>
Add a source from the https address of its file. Prints how many entries it listed.
eider source list
List the sources you have added. Says when a source needs a refresh because it was saved under an older merge rule.
eider source remove <url>
Remove a source, by the address it was added with. Apps installed from it stay installed.
eider source refresh [<url>]
Fetch a source again; every source when no address is given.
eider source export [--format json|text] [-o <file>]
Write the sources you have added as a file you can import elsewhere. JSON is the Eider sources file (the default); text is one address per line. Output goes to stdout unless --output is given.
eider source import <file>
Add the sources listed in a file, or - for standard input. It reads an Eider sources file, a JSON array of addresses, or plain text with one address per line (# starts a comment). Addresses already added are skipped. Exits with status 2 when any address was rejected or failed, after adding the rest.

eider search

eider search [<term>] [--json]

Find apps in your sources; with no term, all of them. The term is part of an app's name, bundle id, developer or subtitle. With --json each result carries the full entry id you need when several apps share a bundle id.

eider info

eider info <bundle-id> [--json]

Show what a source offers for an app, and whether it is installed. The argument is the bundle id, or the full entry id when several apps share the bundle id; in that case the command lists the candidates rather than guessing.

eider install

eider install [<options>] <target>

The target is a .ipa file, an https address of one, the bundle id of an app in your sources, or its full entry id when several share the bundle id. The argument is treated as a file or address only when it contains a slash or ends in .ipa; otherwise it is a bundle id.

OptionMeaning
--version <version>Install this version (bundle id installs only; default is the newest).
--dest <folder>Install into this folder instead of /Applications.
--interface-size <size>How large the app draws: auto (default), 77 (iPad), 85, 100, 115 or mac (Mac idiom). Change it later with eider scale.
--mac-idiomRender in the Mac idiom (1:1 with the display).
--no-keychainNo emulated keychain: logins will not survive a relaunch.
--dylib <file>Also link this prebuilt .dylib into the app. Repeatable.
--name <name>Install under this name instead of the app's own.
--bundle-id <id>Install under this bundle id instead of the app's own.
--remove-extensionsDrop app extensions, a common reason an app fails to sign or open.
--resetClear the app's saved data first. The app must be quit.
--forceReplace a same-named app even if its bundle id differs.
--jsonOne JSON object per line; the last is the result.
 
eider install com.example.app                       # newest version from your sources
eider install com.example.app --version 1.2.0
eider install ~/Downloads/App.ipa --dest ~/Applications --interface-size 100
eider install https://example.com/App.ipa --remove-extensions

eider list

eider list [--json]

List installed apps and mark those with an update.

eider update

eider update [<bundle-id>] [--all] [--interface-size <size>] [--json]

Reinstall the newest version of an app, keeping its data. --all updates every app that has an update. --interface-size also sets how large the app draws; it is kept from the installed app otherwise.

eider uninstall

eider uninstall <bundle-id> [--remove-data] [--json]

Move an installed app to the Trash and forget it. --remove-data also moves the app's data container to the Trash.

eider open

eider open <bundle-id> [--timeout <seconds>] [--settle <seconds>] [--json]

Open an installed app in the background and confirm it stays running. --timeout is how long to wait for the app to come up (default 20); --settle is how long it must stay up to count as running (default 8; must be less than --timeout).

eider scale

eider scale [<bundle-id>] [<size>] [--all] [--json]

Show or set how large an installed app draws. iPad apps draw at 77% on the Mac; Auto is 100% on the built-in display and a little more on a desk display. The app picks a change up when it next opens: no reinstall. Leave out the size to show the current one. With --all, the size is set on every installed app. See Interface Size.

eider doctor

eider doctor <bundle-id> [--timeout <seconds>] [--settle <seconds>] [--json]

Launch an installed app and, if it does not stay up, say why, with a stable diagnosis code. Same options as open. The codes are explained under launch diagnostics.
