Eider

Add sources. Browse apps. Install iPhone and iPad apps as ordinary Mac apps on Apple silicon.

Pre-release. Apple silicon, macOS 14 or later. Ad hoc signed, not notarized. MIT licence.

What Eider is

Eider reads a source, a JSON file at a web address that lists apps, downloads the decrypted .ipa archives it points to, and installs each one so it opens like any other app on your Mac. It comes in three parts that share one engine where they can.

Eider for Mac

A SwiftUI app laid out like the Mac App Store: Library, Updates, Browse, Activity and Sources.

The eider command

Sources, search, install, update, diagnostics and interface size from the terminal, with JSON output for scripts. It ships inside the app bundle.

Eider for iOS In development

The same sources and browsing on iPhone and iPad, with a Certificates section for your own signing identities and installation on the device itself.

The app

Screenshots drawn by the app's own --snapshot mode against a test source with made-up apps.

Features

Every feature has a section on its page. Nothing here is claimed that the documentation does not support, and the pages say what is still unverified.

Sources

AltStore format and PlayCover-style lists, import and export, refresh, warnings, a strict URL policy and a 64 MB size cap.

Browse and search

One row per app: entries with the same bundle id and name merge, with every version kept.

App detail and versions

Screenshots, What's New, information and a version history to install from.

Downloads

Resumable, size-capped, checked against a published SHA-256 and the first hash an address served.

Install on Mac

Mach-O conversion to Mac Catalyst, ad hoc signing and a sandbox entitlement set. No Xcode needed.

Compatibility shims

Keychain, app groups, OpenGL ES, CallKit and camera fixes, plus a per-app quirks table.

Interface Size

iPad apps draw at 77% on a Mac. Pick Auto, 85%, 100%, 115% or the Mac idiom, no reinstall.

Library

An icon grid of installed apps with Open, Update, Diagnose, Show in Finder and Uninstall.

Updates and Update All

Matched to the entry an app was installed from, with a sidebar and Dock badge count.

Launch diagnostics

eider doctor launches an app and, if it dies, says why with a stable code.

Certificates (iOS)

Your own development, ad hoc or enterprise certificate, kept with its password in the Keychain.

Install on device (iOS)

Sign with your certificate and install through a manifest server you run, or a pairing mode in development.

Security model

Sources and IPAs are untrusted. Encrypted IPAs are refused. Nothing from an IPA runs at install time.

Privacy

No analytics or telemetry code. State stays on your machine.

Install

Homebrew

brew tap ayush5harma/eider {{repo}}
brew install --cask eider

The cask installs Eider.app and links the eider command onto your PATH.

Download

Take Eider-{{version}}.zip from the release page and move Eider.app to /Applications. The command is at Eider.app/Contents/Resources/cli/bin/eider. There is also a command-line tarball.

First launch. Eider is ad hoc signed, not notarized. Open it once and approve it in System Settings > Privacy & Security.

Every release so far is marked pre-release on GitHub, so there is no “latest release” shortcut; the releases page lists them all with what was and was not checked in each.

Status and honesty

Early software. Version {{version}} is a pre-release. Expect rough edges, and read limitations and known issues before installing anything you depend on.

  • Each release's notes say what was checked and what was not. The 0.1.7 notes, for example, say Update and Update All had not been run against a real app with a newer version, and the later notes do not report that gap closed.
  • Eider for iOS is not released as an app. Its on-device install has been proved on one iPhone with a hand-written manifest; the whole flow with the manifest server set inside the app is still to be run. The pairing method is not in the build yet. See its status.
  • Eider ships no sources and decrypts nothing. Use it only with apps you have the right to run. See the no-piracy stance.
